# Slide Drill

授業スライド（PDF・PowerPoint など）を入れるだけで、Claude が4〜5択の選択問題（MCQ）を作るドリルアプリです。答えるとすぐに正誤・解説・スライドの該当箇所が表示され、まちがえた問題は自動で復習に回ります。

**使う：https://numashun0910.github.io/slide-drill/**

## できること

- **問題を自動で作る**：PDF・PPTX・DOCX・TXT・MD・画像に対応。複数ファイルをまとめて1つのデッキにできます。スライド内の図（SmartArt）や画像、発表者ノートも読み取ります。
- **重要度順に出題**：各問題に ★★★（最重要）〜 ★（基本）がつき、大事なものから解けます。
- **出典つき**：どの問題にも「ファイル名・スライド番号・見出し・スライドの該当文」が表示されます。
- **和訳と解説**：問題文は資料と同じ言語（英語の授業なら英語）、解説は日本語、のように選べます。
- **復習のしくみ**
  - まちがえた問題は、その場で **4問後にもう一度** 出ます（1回の学習で最大2回）。
  - **苦手**：1回以上まちがえて、まだ2回続けて正解していない問題。
  - **1回以上 / 2回以上まちがえた問題** だけを選んで解けます。
  - **今日の復習**：正解するたびに次の復習までの間隔が 1日 → 3日 → 7日 → 16日 → 35日 とのび、まちがえるとすぐ戻ります。
  - 結果画面から「まちがえた問題を解き直す」をワンクリックで。
- **書き出し・読み込み**：デッキを `.json` で書き出して、別のパソコンや友だちと共有できます（学習記録つき / 問題だけ）。

## 使い方

1. 右上の「設定」で Claude の API キーを入れます（[Anthropic Console](https://console.anthropic.com/settings/keys) で作成）。
2. 「作る」でファイルを入れて「問題を作る」を押します。スライド20枚・標準の量なら1〜3分ほどです。
3. デッキを開いて「この条件で始める」。キーボードの `1`〜`5`（または `A`〜`E`）で回答、`Enter` で次へ、`T` で和訳の表示切り替え。

### API キーがない場合

「読み込む」画面の「Claude.ai などのチャットで作る」を使います。プロンプトをコピーして Claude.ai にファイルと一緒に送り、返ってきた JSON を貼り付けると取り込めます。

## 費用

API キーを使う場合、料金はあなたの Anthropic アカウントに請求されます。生成のあとに費用の目安を表示します。

| モデル | 入力 / 出力（100万トークンあたり） | スライド20枚・標準の量の目安 |
|---|---|---|
| Claude Opus 5.5（初期設定） | $4 / $20 | 0.5 ドル前後 |
| Claude Sonnet 5.5 | $2 / $10 | 0.25 ドル前後 |
| Claude Haiku 5.5 | $0.10 / $0.50 | 0.02 ドル前後 |

目安は「考える深さ：深く」のときのもので、資料の文字量や画像の数で前後します。

## データとプライバシー

- デッキと学習記録はブラウザの **IndexedDB**、設定と API キーは **localStorage** に保存されます。どこのサーバーにも送られません。
- 問題を作るときだけ、ブラウザから **Anthropic の API（api.anthropic.com）に直接** ファイルの内容と API キーが送られます。
- 共用のパソコンでは、使い終わったら「設定」から API キーを削除してください。
- ブラウザのデータを消すとデッキも消えます。大事なデッキは書き出しておいてください。

## 制限

- `.ppt`（古い PowerPoint）・`.key`・`.doc` は読めません。PDF か `.pptx` / `.docx` に書き出してから入れてください。
- PDF は 22MB まで。大きい場合はページを分けてください。
- AI が作る問題なので、まれに不正確なものがあります。おかしい問題は「この問題を今後出さない」で除外できます。

## 開発

ビルド不要の静的サイトです（HTML + ES Modules）。外部ライブラリは CDN から読み込みます：[Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript)（jsDelivr）、JSZip・PDF.js（cdnjs）。

```bash
python3 -m http.server 8000
```

で起動し、`http://localhost:8000/` を開きます。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組みとスタイル |
| `app.js` | 画面・学習・復習のロジック |
| `generate.js` | ファイルの読み取りと Claude API での問題生成 |
| `db.js` | IndexedDB / localStorage への保存 |
